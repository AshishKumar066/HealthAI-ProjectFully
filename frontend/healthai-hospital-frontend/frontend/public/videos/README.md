# HealthAI videos

- `healthai-intro.mp4` is the original hero background video. It remains unchanged.
- `Doctor.mp4` is used in the new guide section below the hero, on the right side.
- The guide section's left side contains animated text and hover-responsive feature cards.

To use a different video in the guide section, replace `Doctor.mp4` with your preferred clip (keep the filename) or update the `src` in `src/pages/Dashboard.jsx`.
